# Linear Patch Antenna

- This page contains the schematic, PCB layout, and HFSS simulation files for a linearly polarized patch antenna, centered at 2.245 GHz I designed for testing purposes for UTAT (University of Toronto Aerospace Team)
- It features a coaxial probe feed into the board
- Substrate chosen is FR4 (1.6mm board thickness) since this is a low cost testing prototype

## S-Parameter Results

- S11 return loss of -39.29 dB at operating frequency of 2.245 GHz
- -15 dB bandwidth of 27.1 MHz
